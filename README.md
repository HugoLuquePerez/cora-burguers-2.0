# CoraBurguers Málaga

Sitio web de presentación para CoraBurguers, un restaurante especializado en burguers y camperos en Málaga.

- Sitio web en vivo: https://cora-burguers-2-0.vercel.app/
- Funcionalidad principal: carta interactiva con secciones 

## Contenido del proyecto

- `index.html` — estructura principal de la página.
- `css/styles.css` — estilos y diseño visual.
- `js/main.js` — comportamiento del menú y slider de hero.
- `assets/` — imágenes y recursos del sitio.

## Notas

El proyecto incluye una carta desplegable con secciones ancladas para facilitar la navegación entre los diferentes apartados del menú.
